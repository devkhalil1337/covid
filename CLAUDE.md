# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

An Apache Cordova hybrid mobile app published to the Play Store as "Stats Viewer"
(widget id `com.coronapk.pk`, app name `StatsViewer`). Despite the repo name
`covid` and the legacy package id, the current app displays public statistics for
Pakistan (rainfall, GDP, debt, population, etc.) fetched live from open APIs.
There is no backend in this repo — all data comes from third-party HTTP APIs.

Target platforms: `browser` and `android` (cordova-android 12, targetSdk 35).

## Commands

```bash
# Run in the browser for fast iteration (no device needed)
cordova run browser            # serves www/ and opens a browser

# Android
cordova build android          # debug APK
cordova build android --release   # signed release, uses build.json keystore config
cordova run android            # build + deploy to connected device/emulator

cordova prepare                # copy www/ into platforms/ after editing source
cordova platform ls            # show installed platforms
```

There is no test suite, lint, or build step for the web assets — `npm test` is a
placeholder that exits 1. Edits to `www/` are plain static files; just re-run /
re-prepare to see them.

## Architecture

- **`www/`** is the entire application source. Everything in `platforms/` is
  generated by Cordova from `www/` + `config.xml` — never edit `platforms/`
  directly; edit `www/` and re-run `cordova prepare`/`build`.
- **`www/index.html`** is the app. It is self-contained: the AngularJS 1.x module
  (`myApp` / `myCtrl`) and all data-fetching logic live in an **inline `<script>`
  block at the bottom of this file**, not in the separate JS files. When changing
  app behavior, edit the inline controller in `index.html`.
- Data sources called directly from the controller:
  - Open-Meteo (`api.open-meteo.com`) for daily rainfall (lat/long hardcoded to Lahore).
  - World Bank API (`api.worldbank.org/v2/country/PK/indicator/...`) for each
    financial/population stat and the GDP chart. Each indicator is a separate GET;
    `getLatestValidValue` picks the record matching `$scope.selectedYear`.
  - Chart.js (CDN) renders the GDP line chart into `#gdpChart`.
- `access origin="*"` + cordova-plugin-whitelist allow these cross-origin calls.

### Note on the loose JS files

`www/js/controller.js`, `index.js`, and `method.js` exist but are **not referenced**
by `index.html` (which uses its own inline controller). Treat `index.html`'s inline
script as the source of truth unless you wire these files in explicitly.

## Release signing

`cordova build android --release` reads `build.json`, which points to
`coronapk.keystore` (alias `coronapk`). The keystore and its passwords are
committed in this repo (`build.json`, `keystore.txt`) — be aware these are
real signing credentials when handling the repo.

## Version bumping

App version lives in **`config.xml`** (`<widget version="...">`, currently 2.0.2),
which is what the store uses — not `package.json` (still 1.0.0). Update
`config.xml` for releases.
